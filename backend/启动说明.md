# 后端启动说明

## 1. 首次准备

在 PowerShell 中执行：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
pip install -r requirements.txt
```

如尚未配置环境变量，复制示例文件并按本机修改：

```powershell
Copy-Item .env.example .env
```

使用 PostgreSQL 持久化时，`.env` 至少确认：

```env
REPOSITORY_BACKEND=database
DATABASE_URL=postgresql+psycopg://postgres:root@127.0.0.1:5432/aesthetic_trajectory
```

首次或 schema 变更后，先执行迁移：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
python -m alembic upgrade head
```

## 2. 启动后端

### 方式 A：PowerShell（推荐）

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 方式 B：仅内存存储（不依赖 PostgreSQL）

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
$env:REPOSITORY_BACKEND = "memory"
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 方式 C：Git Bash / WSL

```bash
cd /e/projectIDEA/AestheticTrajectory/backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## 3. 启动后检查

浏览器或命令行访问：

```text
http://127.0.0.1:8000/api/health
```

应返回健康状态 JSON。

API 文档：

```text
http://127.0.0.1:8000/docs
```

## 4. 常用辅助命令

运行测试（项目默认使用 memory 后端，避免污染 PostgreSQL 业务数据）：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
$env:REPOSITORY_BACKEND = "memory"
python -m pytest app/tests -q
```

在 PostgreSQL 模式下验证持久化：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
$env:REPOSITORY_BACKEND = "database"
python -m pytest app/tests/unit/test_database_repositories.py app/tests/integration/test_api_flow.py -q
```

清空本地 PostgreSQL 业务数据（保留 schema 与 migration 记录）：

```powershell
cd e:\projectIDEA\AestheticTrajectory
python scripts/reset_database.py
```

## 5. 前端联调

前端默认连接 `http://127.0.0.1:8000`。另开终端启动前端：

```powershell
cd e:\projectIDEA\AestheticTrajectory\frontend
npm install
npm run dev
```

前端地址通常为 `http://127.0.0.1:5173`。
