# 后端启动说明

## 1. 首次准备

在 PowerShell 中执行：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
pip install -r requirements.txt
```

如尚未配置环境变量，复制示例文件并按本机修改：

```powershell
Copy-Item .env.example .env
```

使用 PostgreSQL 持久化时，`.env` 至少确认：

```env
REPOSITORY_BACKEND=database
DATABASE_URL=postgresql+psycopg://postgres:root@127.0.0.1:5432/aesthetic_trajectory
```

首次或 schema 变更后，先执行迁移：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
python -m alembic upgrade head
```

## 2. 启动后端

### 方式 A：PowerShell（推荐）

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 方式 B：仅内存存储（不依赖 PostgreSQL）

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
$env:REPOSITORY_BACKEND = "memory"
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### 方式 C：Git Bash / WSL

```bash
cd /e/projectIDEA/AestheticTrajectory/backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

## 3. 启动后检查

浏览器或命令行访问：

```text
http://127.0.0.1:8000/api/health
```

应返回健康状态 JSON。

API 文档：

```text
http://127.0.0.1:8000/docs
```

## 4. 常用辅助命令

运行测试（项目默认使用 memory 后端，避免污染 PostgreSQL 业务数据）：

```powershell
cd e:\projectIDEA\AestheticTrajectory\backend
$env:REPOSITORY_BACKEND = "memory"
python -m pytest app/tests -q
```

在 PostgreSQL 模式下验证持久化：

```powershell

python -m pytest app/tests/unit/test_database_repositories.py app/tests/integration/test_api_flow.py -q
```

清空本地 PostgreSQL 业务数据（保留 schema 与 migration 记录）：

```powershell

python scripts/reset_database.py
```

## 6. 本机 Ollama（场景 E / embedding）

`.env` 使用 `EMBEDDING_RUNTIME=ollama` 时，需先启动 Ollama 并拉取模型：

```powershell
ollama pull nomic-embed-text
```

**Windows 用户名含中文时**，Ollama 默认模型目录 `C:\Users\<用户名>\.ollama` 可能乱码，导致分析时报 `500` / `failed to load model`。请改用项目内英文路径：

```powershell
cd e:\projectIDEA\AestheticTrajectory
powershell -ExecutionPolicy Bypass -File .\scripts\start-ollama.ps1
```

该脚本会设置 `OLLAMA_MODELS=E:\projectIDEA\AestheticTrajectory\ollama-models` 并重启 Ollama。

验证 embedding 是否正常：

```powershell
python -c "import json,urllib.request; r=urllib.request.urlopen(urllib.request.Request('http://127.0.0.1:11434/api/embed', data=json.dumps({'model':'nomic-embed-text','input':'test'}).encode(), headers={'Content-Type':'application/json'}, method='POST'), timeout=60); print(len(json.loads(r.read())['embeddings'][0]))"
```

应输出 `768`。然后再重启 `uvicorn` 并重新分析。

## 7. 本机 Chroma（场景 D / 向量写入）

`.env` 使用 `CHROMA_ENABLED=true` 时，需先启动 Chroma 服务。**Windows 上请显式绑定 `127.0.0.1`**，不要用默认的 `localhost`（可能只监听 IPv6 `[::1]`，客户端访问会得到 `502 Bad Gateway`）：

```powershell
chroma run --host 127.0.0.1 --path e:\projectIDEA\AestheticTrajectory\chroma_data --port 8001
```

启动后验证（应返回 `200`，不是 `502`）：

```powershell
python -c "import httpx; r=httpx.get('http://127.0.0.1:8001/api/v2/heartbeat'); print(r.status_code, r.text[:80])"
```

再重启 `uvicorn` 并重新分析。Debug 面板中 Chroma 边界应显示 `dev_only`，collection 名类似 `inputs_ollama_768`。

## 8. V6-A 图片理解 runtime

V6-A 新增 image feature runtime 配置：

```env
IMAGE_FEATURE_RUNTIME=mock
IMAGE_FEATURE_MODEL=mock-image-feature-v1
IMAGE_FEATURE_TIMEOUT_SECONDS=120
```

可选值：

```text
mock：默认路径，生成 dev-only 图片占位特征，不代表真实视觉理解。
disabled：输入含 image 时 fail-fast，用于验证不会 silent fallback mock。
ollama_vision：调用 Ollama vision 模型；需先部署支持图片输入的模型。
```

当前如果尚未部署 vision 模型，保持：

```env
IMAGE_FEATURE_RUNTIME=mock
```

部署真实 vision 模型后，再改为：

```env
IMAGE_FEATURE_RUNTIME=ollama_vision
IMAGE_FEATURE_MODEL=<你的视觉模型名>
OLLAMA_BASE_URL=http://127.0.0.1:11434
```

然后重启 `uvicorn` 并做图片上传分析人工验收。真实 runtime 配置错误时应失败，不会静默回退 mock。

## 9. V6-B 音乐理解 boundary

V6-B 新增 music feature runtime 配置：

```env
MUSIC_FEATURE_RUNTIME=metadata_only
```

可选值：

```text
metadata_only：默认路径，只使用 title / description / URL metadata，不声称解析音频。
text_notes：使用用户主动提供的 lyrics / transcript / notes 作为文本证据。
mock：dev-only 占位，不代表真实音乐理解。
disabled：输入含 music 时 fail-fast，用于验证不会 silent fallback mock。
```

当前不需要部署 ASR 或音频模型。若 music 输入只有曲名或链接，保持：

```env
MUSIC_FEATURE_RUNTIME=metadata_only
```

如果用户会在 `contentText` / `description` 中提供歌词、转录或听感笔记，可改为：

```env
MUSIC_FEATURE_RUNTIME=text_notes
```

V6-B 首版不下载流媒体内容，不抓取版权音频，不做完整 ASR / 节拍 / 音色分析。
