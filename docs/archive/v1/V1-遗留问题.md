## 4. V1-A 已收口内容

2026-06-16 已完成：

- 新增 `FeatureExtractor` 抽象，workflow 可注入不同 extractor。
- 默认保留 `MockFeatureExtractor`，现有 mock workflow 和 API 路径不变。
- 新增本地 `HeuristicFeatureExtractor`，用于文本特征抽取边界。
- `InputFeature` schema 新增 `modelName`，并要求 feature evidence 非空。
- 新增 `validate_input_feature`，阻止缺少 `promptVersion`、`modelName` 或 evidence 的 feature 进入 workflow。
- 图片输入当前明确为 placeholder feature：真实图片分析依赖后续文件存储接入。

## 5. V1-B 已收口内容

2026-06-16 已完成：

- 新增 `EmbeddingClient` 抽象，workflow 可注入 embedding client。
- 保留 `MockEmbeddingClient`，现有 mock workflow 和 API 路径不变。
- 新增 embedding text builder，明确文本输入和图片 placeholder 的 embedding text 构造规则。
- 新增 cosine similarity helper，校验空向量、全零向量和维度不一致。
- 新增 threshold graph / connected components 小样本分组。
- `commonFeatures` 优先来自 `InputFeature.lowLevelFeatures` 的 feature key/value overlap。
- 少于 3 个样本时不生成 similarity group。
- ChromaDB 当前仍是 metadata 边界，不接 runtime add/query。
