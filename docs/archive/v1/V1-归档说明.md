## 2. V1 一句话目标

```text
用户上传 3-10 个图片 / 文本样本，系统保存输入，提取底层特征，生成 embedding，做小样本相似性分组，生成有证据绑定的审美报告，并保存用户反馈。
```

## 5. 待最终确认

后续真实 V1 仍需确认：

- 当前 repository 是 PostgreSQL 实现、in-memory mock，还是混合状态。
- ChromaDB 是真实 runtime 连接、mock，还是抽象占位。
- mock AI 输出是否全部符合 V1 schema。
- report insight 是否都具备 evidence ref。
- analysis log 是否记录 step、状态、模型、耗时和错误。
- 真实图片文件是否保存。
- 图片内容是否进入真实多模态分析。
