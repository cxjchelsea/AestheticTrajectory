# AI 审美形成系统：V1 验收核对表

## 1. 使用方式

这份表用于最终确认 V1 是否可以正式归档。

状态说明：

```text
[ ] 未核对
[~] 部分完成
[x] 已完成
[-] V1 不适用
```

正式归档前，所有 V1 必做项都应该是 `[x]`，或者在 `V1-遗留问题.md` 中说明为什么可以延后。

## 2. 前端页面

- [x] 首页包含产品一句话说明、上传入口、示例洞察。
- [~] 上传页支持图片上传。
- [x] 上传页支持文字输入。
- [x] 上传页支持样本预览。
- [x] 上传页支持删除样本。
- [x] 上传页展示样本数量提示。
- [x] 上传页限制最少 3 个样本、建议 5-10 个样本、最多 12 个样本。
- [x] 分析等待页展示读取样本、提取特征、生成向量、寻找相似性、生成报告。
- [x] 报告页展示总体摘要。
- [x] 报告页展示底层特征摘要。
- [x] 报告页展示相似性分组。
- [x] 报告页展示可能解释。
- [x] 报告页展示重点洞察。
- [~] 报告页展示证据。
- [x] 报告页支持反馈按钮：不像我、不确定、有点像、很像我。

## 3. API

- [x] `GET /api/health` 可用。
- [x] `POST /api/inputs` 可创建图片或文本输入。
- [x] `POST /api/analysis-jobs` 可创建分析任务。
- [x] `GET /api/analysis-jobs/{job_id}` 可查询分析状态。
- [x] `GET /api/reports/{report_id}` 可查询报告。
- [x] `POST /api/insights/{insight_id}/feedback` 可提交反馈。

## 4. 数据与存储

- [x] 输入样本可以保存。
- [x] 图片 / 文本底层特征可以保存。
- [x] embedding metadata 可以保存。
- [~] 向量可以写入 ChromaDB，或在 V1 mock 阶段有明确替代实现。
- [x] 分析任务状态可以保存和查询。
- [x] 报告可以保存。
- [x] possible interpretations 可以保存或作为报告结构的一部分返回。
- [~] insights 可以保存。
- [x] insight feedback 可以保存。
- [x] analysis logs 可以记录 step、状态、模型、耗时和错误。

## 5. AI / Workflow

- [x] 图片底层特征 mock 符合 schema。
- [x] 文本底层特征 mock 符合 schema。
- [x] `FeatureExtractor` 抽象已建立，workflow 可注入 extractor。
- [x] 默认 workflow 仍保留 mock extractor，不改变现有 API 行为。
- [x] 文本输入已有本地启发式 extractor 边界。
- [x] 图片输入已明确 placeholder 边界，真实分析依赖后续文件存储接入。
- [x] `InputFeature` 包含 `promptVersion` 和 `modelName`。
- [x] 非法 feature 输出可被 validator 识别。
- [x] embedding mock 或真实 embedding 输出稳定。
- [x] `EmbeddingClient` 抽象已建立，workflow 可注入 embedding client。
- [x] embedding text builder 已明确文本 / 图片 placeholder 的输入构造规则。
- [x] 相似度计算有单元测试覆盖。
- [x] 小样本相似性分组基于 threshold graph / connected components。
- [x] `commonFeatures` 优先来自 feature key/value overlap。
- [x] 相似性分组输出 1-3 个组，样本不足时可跳过分组。
- [x] possible interpretations 绑定输入证据。
- [x] 报告生成包含 summary、similarity groups、possible interpretations、insights。
- [x] 每条 insight 至少有一个 evidence ref。
- [x] 报告包含非诊断声明或等价表达。
- [x] workflow 能从创建任务执行到保存报告。
- [x] workflow 不执行 V2 的用户画像更新。

## 6. 边界与表达

- [x] 不包含完整登录系统。
- [x] 不包含历史报告列表。
- [x] 不包含报告对比。
- [x] 不包含长期用户画像。
- [x] 不包含 RAG。
- [x] 不包含 Agent。
- [x] 不包含 MCP。
- [x] 不包含知识图谱。
- [x] 不包含音乐 / 视频输入。
- [x] 不包含自动推荐。
- [x] 报告不做人格诊断。
- [x] 报告不使用玄学表达。
- [~] 报告不使用无证据高级词。
- [x] 相似性分组不被包装成绝对聚类结论。
