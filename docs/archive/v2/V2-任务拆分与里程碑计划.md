## 3. V2 一句话目标

```text
在 V1 的报告与反馈闭环之上，加入历史报告、轻量画像、可追溯 profile evidence，以及 feedback 对画像的修正能力。
```

V2 只形成：

```text
基于用户输入、报告洞察和用户反馈的轻量审美观察记录。
```

V2 不生成人格画像、心理评估或推荐决策。

## 5. V2 里程碑

### 5.1 Milestone 1：版本级研究与边界确认

目标：

```text
先明确 V2 的 memory object、profile evidence、feedback governance、遗忘 / 冲突 / 可解释规则，再进入代码实现。
```

完成结果：

- 完成 V2-0 版本级研究。
- 将长期设计决策上升到 `../../07-数据结构与系统架构文档.md`、`../../11-模块拆分与接口测试文档.md`、`../../13-验证与评估文档.md`。
- 明确 V2 不实现 RAG、Agent、MCP、真实 LLM / vision / embedding runtime。

### 5.2 Milestone 2：历史报告可回看

目标：

```text
用户能看到历史报告列表，并从历史列表进入报告详情。
```

完成结果：

- 新增历史报告列表 API。
- 新增历史报告页。
- 历史报告按用户过滤、按时间倒序返回。
- 历史报告详情不依赖前端 mock data。

### 5.3 Milestone 3：轻量画像与证据链

目标：

```text
基于 reports + feedback 构建可追溯、可解释、不过度推断的轻量画像。
```

完成结果：

- 新增 `user_profiles`、`profile_items`、`profile_evidence`。
- 新增只读 profile API。
- 新增前端轻量画像页。
- 画像页展示 summary、items、evidence refs、feedback evidence。
- 页面不输出人格、心理或能力诊断式表达。

### 5.4 Milestone 4：feedback 影响画像

目标：

```text
用户反馈可以修正画像，not_me / unsure 不被强化为正向画像。
```

完成结果：

- feedback rating 映射为 profile evidence direction / weight_delta。
- 同一 `user_id + insight_id` 再次反馈时更新当前 feedback，不重复累计。
- mock / fallback 报告不写入真实 feedback 或画像。
- 真实报告 feedback 提交和修改已通过人工测试。

### 5.5 Milestone 5：最近报告变化说明

目标：

```text
用户能看到最近两次报告之间的可追溯变化说明。
```

完成结果：

- 新增 `GET /api/users/{user_id}/reports/comparison/latest`。
- 对比最近两份 `aesthetic_reports.report_json`，不新增持久化表。
- 前端新增最近变化页和历史页入口。
- 最近变化页展示 summary、feature changes、interpretation changes 和 evidence refs。

### 5.6 Milestone 6：记忆治理验收

目标：

```text
验证 V2 记忆系统 evidence-first、可修正、不过度推断。
```

完成结果：

- 新增 V2-E memory governance 自动测试。
- 覆盖 profile evidence coverage。
- 覆盖 `not_me` / `unsure` 治理。
- 覆盖被否定解释不复现为正向 profile item。
- 覆盖 feedback 更新只使用最新 snapshot。
- 后端完整测试和前端 build 通过。

### 5.7 Milestone 7：V2 final closure 与 archive gate

目标：

```text
复核完整用户路径、PostgreSQL runtime 表数据和页面表达边界，并正式归档。
```

完成结果：

- 用户已确认最终完整路径测试成功。
- PostgreSQL runtime 表数据复核通过：无重复 inputs、无 orphan feedback、profile evidence 可追溯。
- 页面整体不输出人格、心理或能力诊断式表达。
- V2 archive gate 已完成。

## 6. V2 明确不做

V2 不实现：

- 完整登录系统。
- 真实图片文件存储。
- 真实图片内容读取。
- 真实 LLM / vision / embedding runtime。
- ChromaDB runtime 写入和查询。
- personalized retrieval。
- RAG / 审美知识库。
- Agent / MCP。
- 知识图谱。
- 音乐 / 视频输入。
- 自动推荐。
- 用户画像的复杂手动编辑、删除和权限工作流。
