## 3. API

### 3.1 已验收能力

- [x] `GET /api/users/{user_id}/reports` 可查询历史报告列表。
- [x] 历史报告列表返回 `ReportHistoryResponse`。
- [x] 历史报告列表包含 `reports`、`total`、`limit`、`offset`。
- [x] 历史报告摘要包含 `reportId`、`jobId`、`title`、`summary`、`inputCount`、`createdAt`。
- [x] 历史报告按创建时间倒序返回。
- [x] 历史报告按 `user_id` 过滤。
- [x] `GET /api/reports/{report_id}` 存在报告时返回 `ReportResponse`。
- [x] `GET /api/reports/{report_id}` 不存在报告时返回 404。
- [x] `GET /api/users/{user_id}/profile` 可查询用户轻量画像。
- [x] profile 有 evidence 时返回 `UserProfile`。
- [x] profile 无足够 evidence 时返回 `profile: null` 和明确 message。
- [x] `GET /api/users/{user_id}/reports/comparison/latest` 可查询最近两次报告对比。
- [x] 历史报告不足两份时 comparison API 返回明确 message，不生成变化。
- [x] comparison API 返回 feature changes、interpretation changes、summary、disclaimer 和 evidence refs。

### 3.2 已修复但仍属于收口观察项

- [x] `GET /api/insights/{insight_id}/feedback` 已反馈时返回当前 feedback。
- [x] `GET /api/insights/{insight_id}/feedback` 未反馈时返回 `null`。
- [x] `POST /api/insights/{insight_id}/feedback` 可提交 feedback。
- [x] `POST /api/insights/{insight_id}/feedback` 可修改同一 insight 的 feedback。
- [x] 不存在的 insight 提交 feedback 时返回 404。
- [x] 非法 rating 提交时返回 422。

### 3.3 未完成或待最终复核

- [~] `GET /api/analysis-jobs/{job_id}/debug` 已可用，但只应作为开发能力，生产前端不可展示。
- [ ] V2 API 全量回归尚未作为最终归档验收执行。

- [x] 不包含完整登录系统。
- [x] 不包含真实图片文件存储。
- [x] 不包含真实图片内容读取。
- [x] 不包含真实 LLM / vision / embedding runtime。
- [x] 不包含 ChromaDB runtime 写入和查询。
- [x] 不包含 personalized retrieval。

- [x] 不包含知识图谱。
- [x] 不包含音乐 / 视频输入。
- [x] 不包含自动推荐。
- [x] 不把画像用于消费引导或自动化重大决策。
- [x] 页面不做人格诊断。
- [x] 页面不做心理评估。
- [x] 页面不使用玄学表达。

- [x] 最近变化页面不把两次输入写成人格、心理或能力变化。
