## 4. 当前观察到的实现快照

已实现前端能力：

- 历史报告页。
- 轻量画像页。
- 最近变化页。
- 报告详情页 feedback 保存和修改入口。
- mock / fallback 报告不写入真实 feedback 的界面保护。
- 开发模式重复提交保护和分析页卡住修复。

已实现后端能力：

- 历史报告列表 API：`GET /api/users/{user_id}/reports`。
- 报告详情 API：`GET /api/reports/{report_id}`。
- 读取当前反馈 API：`GET /api/insights/{insight_id}/feedback`。
- 提交或修改反馈 API：`POST /api/insights/{insight_id}/feedback`。
- 只读画像 API：`GET /api/users/{user_id}/profile`。
- 最近报告对比 API：`GET /api/users/{user_id}/reports/comparison/latest`。
- 分析任务 debug API：`GET /api/analysis-jobs/{job_id}/debug`。
- profile builder，可从 reports + feedback 重建轻量画像。

已实现数据库能力：

- V2 复用 V1 的报告、洞察、反馈和日志表。
- V2 新增 `user_profiles`、`profile_items`、`profile_evidence`。
- `aesthetic_reports.report_json` 支持历史报告详情回看。
- 最近报告对比复用 `aesthetic_reports.report_json`，不新增持久化表。
- `insight_feedback` 支持同一 `user_id + insight_id` 的当前反馈更新语义。

## 6. 后续边界

后续版本仍需确认：

- 真实图片文件存储。
- 图片内容进入真实多模态分析。
- 真实 LLM / vision / embedding runtime。
- ChromaDB runtime 写入和查询。
- personalized retrieval / RAG。
- Agent / MCP / 知识图谱。
- 用户手动隐藏、删除或编辑 profile item 的完整权限与审计工作流。
- 匿名用户持久 ID 或登录系统的身份边界。
- Pydantic / FastAPI alias warning 是否作为 tech debt 单独清理。
