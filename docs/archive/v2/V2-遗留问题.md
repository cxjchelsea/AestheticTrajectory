这份文档记录 V2 收口阶段的遗留问题及其后续处理状态。

状态说明：

```text
resolved：已经在 V2 当前子阶段中解决
pending_validation：功能已实现或局部测试通过，但仍等待最终人工验收或全路径复核
carry_over：尚未解决，明确延后到指定版本或任务
blocking：阻塞 V2 归档，必须先解决
wont_fix：确认不处理，并说明原因
```
