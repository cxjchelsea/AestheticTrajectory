## 1. 文档职责

这份文档记录 V2 收口阶段的遗留问题。

所有问题必须标记状态，不能保留未分类列表。

## 2. 状态枚举

```text
resolved：已由当前或后续版本解决
carry_over：仍然有效，明确转入后续版本
blocking：归档前必须解决
wont_fix：明确不处理，并说明原因
pending_validation：功能已实现或自动验证通过，但仍等待人工验收确认
```
