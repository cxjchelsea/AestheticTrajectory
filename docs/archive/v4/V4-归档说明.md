- **Runtime**：mock / ollama / openai embedding；Chroma input + knowledge collections。
- **多模态**：文件上传、music/video metadata-only。
- **Timeline**：`aesthetic_timeline_events`、timeline API、周期摘要。
- **Knowledge Graph**：concepts、relations（sourceEvidence）、1-hop query。
