## 2. V3 一句话目标

```text
在 V2 Memory / User Model baseline 之上，引入 personalized history retrieval、审美知识 RAG、evaluation metrics 与 retrieval / RAG observability，且不破坏 evidence-first 与 non-diagnostic 表达规则。
```

V3 的增强定义：

```text
历史参考与知识参考只作 explanation support；当前输入 evidence 优先；profile 仍只由 features / insights / feedback 构建。
```

## 4. 当前观察到的实现快照

### 4.1 已实现后端能力

Workflow 新增 step：

- `retrieve_personal_history` → `PersonalHistoryContext`
- `retrieve_aesthetic_knowledge` → `AestheticKnowledgeContext`
- `compute_report_evaluation` → `ReportEvaluationMetrics`

核心服务：

- `personal_history_retrieval.build_personal_history_context`
- `aesthetic_knowledge_retrieval.build_aesthetic_knowledge_context`
- `report_evaluation.build_report_evaluation`
- `observability_trace.build_debug_traces`

API：

- `GET /api/reports/{report_id}/evaluation`
- `GET /api/analysis-jobs/{job_id}/debug`（扩展 retrievalTrace、retrievalItems、contextAssemblyTrace、evaluationTrace）

治理测试：

- `test_v3_governance_validation.py`
- `test_personal_history_retrieval.py`
- `test_aesthetic_knowledge_retrieval.py`
- `test_report_evaluation.py`
- `test_observability_trace.py`

### 4.2 已实现前端能力

- 报告详情「历史参考」分区（V3-A）。
- 报告详情「知识参考」分区（V3-B）。
- 报告详情「质量评估」分区（V3-C）。
- feedback 后 evaluation 自动刷新（`evaluationRefreshKey`）。
- Developer Debug Panel retrieval / context / evaluation trace（V3-D，dev-only）。
- 从历史记录打开报告时传递 `jobId` 以加载 debug。

### 4.3 已实现数据能力

- V3 复用 V2 的 `aesthetic_reports`、`insight_feedback`、`analysis_logs` 等表。
- `aesthetic_reports.report_json` 扩展 `historyContext`、`knowledgeContext`、`evaluationMetrics`。
- V3 不新增 retrieval / evaluation 专用业务表。
- V3-D trace 为读取时组装的视图，不要求 `analysis_logs.detail_json` migration。
- profile 三表语义不变；knowledge / history 不写入 profile evidence。

### 4.4 未进入 V3 runtime

- ChromaDB runtime 写入和查询。
- 真实 LLM / vision / embedding runtime。
- 外部审美知识库 crawl / embedding RAG。
- LangSmith / OpenTelemetry Collector / 外部 observability SaaS。
- Agent / MCP / 知识图谱。
- grouping stability、failure replay 完整 runtime。

## 6. 后续边界

后续版本仍需确认：

- grouping stability、failure replay 评估指标。
- 真实 LLM / vision / embedding runtime。
- ChromaDB runtime 写入和查询。
- 外部知识库 RAG runtime（向量检索、在线更新）。
- LangSmith / OpenTelemetry 生产级 pipeline。
- Agent / MCP / 知识图谱 / 多模态扩展。
- 用户手动隐藏、删除 profile item 的完整权限与审计。
- 匿名用户持久 ID 或登录系统身份边界。
- database 模式 integration test 的数据隔离策略。
- Pydantic / FastAPI alias warning 清理。
