## 4. 当前观察到的实现快照

已实现后端能力：

- Personalized history retrieval：`retrieve_personal_history` workflow step，`PersonalHistoryContext`。
- Aesthetic knowledge RAG：静态知识库检索，`AestheticKnowledgeContext`。
- Evaluation metrics baseline：`compute_report_evaluation` step，`GET /api/reports/{report_id}/evaluation`。
- Retrieval / RAG observability：扩展 `GET /api/analysis-jobs/{job_id}/debug` trace 字段。
- V3-E governance validation：`test_v3_governance_validation.py`。

已实现前端能力：

- 报告详情「历史参考」「知识参考」「质量评估」分区。
- feedback 后 evaluation 自动刷新。
- Developer Debug Panel retrieval / context / evaluation trace 分区（dev-only）。

未进入 V3 runtime：

- ChromaDB runtime 写入。
- 真实 LLM / vision / embedding runtime。
- LangSmith / OpenTelemetry / 外部 observability SaaS。
- Agent / MCP / 知识图谱。
