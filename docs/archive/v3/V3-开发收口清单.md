## 3. V3 收口范围

V3 收口时验收的核心范围：

- V3-0 版本级研究与子阶段拆分。
- V3-A personalized history retrieval（workflow + UI + governance）。
- V3-B aesthetic knowledge RAG（静态 KB + UI + abstention）。
- V3-C evaluation metrics baseline（workflow + API + UI + feedback refresh）。
- V3-D retrieval / RAG observability（debug API + dev panel trace）。
- V3-E stability and governance validation（自动 + 人工全链路）。
- evidence-first：history / knowledge 与 insight evidence 分离。
- RAG 知识不进入 profile positive evidence。
- mock / dev-only 边界诚实标记。
