## 2. V6 版本级验收

- [x] image / audio / video 多模态输入均有明确 runtime boundary。
- [x] metadata-only / placeholder 不被描述为真实内容理解。
- [x] `InputFeature` 仍包含 evidence、promptVersion、modelName。
- [x] report `evidenceRefs` 仍只指向当前 report inputs。
- [x] mock / metadata-only / disabled runtime 边界在 debug 中可见。
- [x] disabled runtime fail-fast，不 silent fallback mock。
- [x] 多模态 feature-only evidence 不会在无 feedback 时形成 `stable` profile item。
- [x] identity scope 不因多模态 report/debug/file/profile 路径被绕过。
- [x] V6 结束前有 archive gate 和 legacy issue audit。

## 3. 后端能力

### 3.1 Image Runtime

- [x] `IMAGE_FEATURE_RUNTIME=mock` 生成 dev-only placeholder。
- [x] `IMAGE_FEATURE_RUNTIME=disabled` fail-fast。
- [x] `IMAGE_FEATURE_RUNTIME=ollama_vision` 有 adapter 与 JSON/schema/governance validation。
- [-] 真实 vision 模型人工验收后置。

### 3.2 Audio / Music Boundary

- [x] `MUSIC_FEATURE_RUNTIME=metadata_only` 不解析音频内容。
- [x] `MUSIC_FEATURE_RUNTIME=text_notes` 使用用户主动提供文本。
- [x] `MUSIC_FEATURE_RUNTIME=disabled` fail-fast。
- [-] 真实 ASR/audio feature runtime 不属于 V6 默认验收。

### 3.3 Video Boundary

- [x] `VIDEO_FEATURE_RUNTIME=metadata_only` 不解析视频内容。
- [x] `VIDEO_FEATURE_RUNTIME=text_notes` 使用用户主动提供文本。
- [x] `VIDEO_FEATURE_RUNTIME=disabled` fail-fast。
- [-] 真实 keyframe/video runtime 不属于 V6 默认验收。

### 3.4 Hardening / Debug

- [x] 默认 pytest baseline 不依赖外部模型服务。
- [x] upload 测试隔离到 pytest 临时目录。
- [x] `.env.example` 与 settings 默认 runtime 一致。
- [x] debug `mockUsage` / `boundaryWarnings` 覆盖 image/music/video runtime 状态。
