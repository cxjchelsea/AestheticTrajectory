## 4. 实现快照（归档时）

### 4.1 后端能力

- **Image Runtime**：`ImageFeatureExtractor` adapter，支持 `mock`、`disabled`、`ollama_vision` 路径。
- **Audio / Music Boundary**：支持 `metadata_only`、`text_notes`、`mock`、`disabled` 路径，不伪造真实音频解析。
- **Video Boundary**：支持 `metadata_only`、`text_notes`、`mock`、`disabled` 路径，不伪造真实视频解析。
- **Runtime Factory**：统一按 input modality 分发 feature extraction。
- **Runtime Debug**：image/music/video runtime 状态进入 `mockUsage` 与 `boundaryWarnings`。
- **Hardening**：默认 pytest 使用 memory backend + mock/metadata-only runtime，upload 测试隔离到 pytest 临时目录。
- **Governance**：V6-E 横切测试覆盖 evidenceRefs、profile governance、identity scope、runtime boundary、disabled fail-fast。

### 4.2 前端能力

- V6 未引入新的前端主流程页面。
- 既有 report/debug/profile 页面继续消费后端 API。
- V6-A/V6-B/V6-C 的 runtime 配置和人工验收路径记录在 `backend/启动说明.md`。

### 4.3 配置 / 测试

- 新增 `.env.example` 多模态 runtime 配置。
- 默认测试基线：
  - `IMAGE_FEATURE_RUNTIME=mock`
  - `MUSIC_FEATURE_RUNTIME=metadata_only`
  - `VIDEO_FEATURE_RUNTIME=metadata_only`
  - `REPOSITORY_BACKEND=memory`
- Pydantic/FastAPI alias compatibility warning 使用精确 pytest filter 管理。

### 4.4 未进入 V6 完整 runtime（延后见遗留问题）

- V6-A 真实 vision 模型人工验收。
- 真实 audio ASR / audio feature extraction。
- 真实 video keyframe / subtitle / remote video extraction。
- 生产级 LangSmith / OpenTelemetry / Sentry。
- Postgres / Chroma / Ollama smoke 自动化进入默认 CI。
