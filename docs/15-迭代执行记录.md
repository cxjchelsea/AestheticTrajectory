# AI 审美形成系统：迭代执行记录

## 1. 文档职责

这份文档记录每轮迭代的实际执行状态。

它不定义版本目标，也不替代验收清单：

- 版本目标以 `02-版本迭代路线图.md` 为准。
- MVP 产品范围以 `03-MVP功能需求文档.md` 为准。
- 当前开发任务以 `12-开发任务拆分与里程碑计划.md` 为准。
- V1 验收清单以 `16-V1开发收口清单.md` 为准。
- 已完成版本的详细归档进入 `archive/<version>/`。

本文档只回答：

```text
这一轮实际做到了什么？
哪些没有完成？
测过什么？
发现了什么问题？
下一轮应该怎么处理？
```

## 2. 记录规则

每个版本完成阶段性开发后，都必须补充：

- 本轮目标。
- 实际完成。
- 未完成。
- 测试记录。
- 主要问题。
- 复盘结论。
- 下一轮入口。

状态枚举：

```text
planned：已规划，未开始
in_progress：开发中
ready_for_validation：等待验收
archived：已归档
blocked：被外部问题阻塞
```
